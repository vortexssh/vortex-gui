# Design — Vortex GUI

Как кабинет и TUI: «терминал / matrix», не корпоративный дашборд.

- Фон `#0a0a0a` (void), панели `#141414`, рамки `#1f1f1f`.
- Акцент `#39ff14`, dim `#9ca3af`.
- Inter для UI, JetBrains Mono для IP, логов, статуса агента.
- Online = точка neon pulse. Offline = muted.
- Тонкие рамки, лёгкий glow на primary CTA и активном хосте.
- Темы Web (matrix / amber / arctic / …) можно повторить позже; MVP = matrix.

TUI login splash: чёрный фон, зелёный monospace «VORTEX» — тот же вайб для callback HTML и about-экрана.
